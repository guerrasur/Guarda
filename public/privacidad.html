Privacidad de Guarda

Actualizado el 20 de octubre de 2026.

Guarda conserva notas, listas, imágenes, dibujos y grabaciones en el navegador. La conexión con Google Drive es opcional.

Google Drive

Si conectás tu cuenta, Guarda usa el permiso drive.file para crear y gestionar sus archivos de sincronización en tu propio Drive. Las notas y los audios viajan directamente entre tu navegador y Google. El acceso se limita a los archivos autorizados para esta aplicación; no se solicita acceso general a todo tu Drive.

La aplicación recibe el identificador de la cuenta, el nombre y el correo para identificar la conexión y evitar mezclar cuentas. El token de acceso solo se mantiene en memoria, incluida una copia temporal para recuperar la conexión al recargar o actualizar, que se consume una sola vez y nunca dura más que el propio token. Ese traspaso se pierde si el navegador termina el proceso y no se utiliza para ampliar la duración del acceso. No se escribe el token en almacenamiento del navegador; no se guarda en el repositorio ni se envía a un servidor propio. Los datos de Google se utilizan para sincronizar tus notas; no se venden ni se utilizan para publicidad o entrenamiento de modelos de inteligencia artificial.

Control y eliminación

Podés desconectar Drive desde Guarda o revocar su permiso desde la configuración de tu cuenta de Google. Desconectar conserva los datos locales y los archivos de Drive. La eliminación definitiva de una nota se propaga durante la sincronización. Otros dispositivos sin conexión y revisiones previas de Drive pueden conservar copias. Podés exportar una copia desde Configuración.

Eliminar los datos del navegador borra las notas y la configuración locales. Los archivos almacenados en Drive pueden gestionarse desde tu propia cuenta. Borrar la carpeta de Drive sin borrar los datos locales puede hacer que vuelvan a subirse si reconectás.

Servicios externos y consultas

La web se publica en GitHub Pages y, al usar Drive, carga Google Identity Services. Se aplican también las políticas de privacidad de GitHub y Google para sus servicios. Consultas y problemas: repositorio de Guarda.
